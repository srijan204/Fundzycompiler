THE BASICS · EXPLAINED SIMPLY

What does each line actually do?

Start with these common lines. You do not need to memorize everything at once.

C LANGUAGE

#include <stdio.h>

Adds standard input/output tools, including printf() and scanf().

PROGRAM START

int main(void)

The main function is where a normal C program begins running.

SHOW OUTPUT

printf("Hello");

Prints the text Hello to the program's output. In C, text is placed inside double quotes.

FINISH

return 0;

Ends the main function and conventionally reports that the program finished successfully.

C++ LANGUAGE

#include <iostream>

Provides C++ input/output tools such as cout and cin.

READ INPUT

cin >> age;

Reads a value from the Input box and stores it in the variable named age.

Quick tip: For the sum, factorial, Fibonacci, and prime examples, enter the input in the Input (stdin) box before pressing Run Code. Example: type 5 for factorial or 7 for prime.
